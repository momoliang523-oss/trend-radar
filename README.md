# 出海热点雷达 · 智能市场调研分析师

以「日历」为主界面的 AI 市场调研工具:每天聚合海外热点与爆款,点开任一热点「延伸分析」,AI 分析师输出 **①爆火原因解读 / ②选品建议 / ③短视频创作建议 / ④内容营销方向** 四类分析(逐项手动点开),支持引用回源、可信度标注与收藏沉淀。

> 把「看到热点」变成「看得懂、抄得动、选得准」。

```bash
TREND_RADAR_ADMIN_EMAILS=你的邮箱 npm start    # 用该邮箱注册登录 = 管理员
```

## 报告页:五板块五问五图 · 固定四段

规则一句话:**先定这一屏要回答什么,再由问题反推图型**——不是先画图再解释。报告页固定四段、顺序不换:① 一句话结论 → ② 5 张趋势图(一图一板块)→ ③ 明细表(可下钻)→ ④ 下周期 3 个动作。

**五个板块、五个问题、五种图**(每张图下一句人话结论,数据全部来自本周期统计):

| 板块 | 回答什么 | 图型 | 一行读法 |
| --- | --- | --- | --- |
| ① 区域热点 | 哪个市场在起 | 多国折线对比 | 哪个市场比上周更热(热度分变化 ≥3 才算趋势,±1-2 为噪声) |
| ② 类目机会 | 该不该加码 | 分组柱(本周 vs 上周) | 哪两个类目值得多投 |
| ③ 话题风向 | 内容怎么跟 | 堆叠柱(构成变化) | 新话题是否从旧话题长出(本周期新话题中与上周同品类数量) |
| ④ 生命周期 | 还来不来得及 | 阶段带(四态区段) | 这个热点还剩几天窗口(历史各阶段平均时长估算) |
| ⑤ 竞品与价格 | 利润还在不在 | 散点(热度 × 来源数) | 价格带是否在下移(⚠️ 价格 × 动销需接入竞品价格数据源,当前以热度 × 来源数观察竞争密度) |

**数据方法(少一步图就会骗人)**:

- **归一化**:热度分本身就是 0-100 指数(采集端四路信号各自归一后加权),避免「爬虫量大的话题永远排第一」
- **切周期桶**:周报按天、月/季报按周切桶后再比方向;周桶看拐点、月桶看季节性;**缺数据的周留空档、不插值**(多国折线缺测断线,插值等于编数)
- **一句话结论**:纯统计即时生成(共 N 条热点 / 抓到 M 个上升信号 / 哪个市场更热 / 哪个类目值得加码 / 优先跟进谁),不依赖模型生成,游客即可见

**四段详情**:

- **① 一句话结论**:brand-soft 高亮卡,把本周期统计压缩成一句话;上升信号带涨幅(涨幅 = 热度分对比话题首次记录,涨幅 ≥20% 单独计数)
- **② 五张趋势图**:多国折线(各地区周均热度,含上一周期作对比基准)/ 分组柱 / 堆叠柱(每周新上榜·延续·退场话题数)/ 阶段带(每行一个话题的生命周期四态色带)/ 竞品散点(点色 = 生命周期,点击进详情);每张图下一行读法;**每卡右上角「🖼 图片」可单独转 PNG**(本地光栅化,不扣积分、无需登录)
- **③ 明细表(可下钻)**:全话题排行表(# / 话题 / 地区 / 类目 / 热度 / 涨幅 / 生命周期 / 来源),点击任意一行下钻话题详情;游客前 3 行可见,其余模糊 + 🔒 登录解锁
- **④ 下周期 3 个动作**:选品(跟进涨幅最大的上升话题)/ 内容(押注当前最热话题)/ 观察(升温最快或回落最快的市场 + 退潮提醒),点击动作卡进详情,纯统计推导、标注参考性质

**其余功能**:

- 顶部**地区筛选 chips**(全部地区 + 美国 / 欧洲 / 东南亚 / 中东 / 日本 / 拉美 / 墨西哥 / 俄罗斯,计数 = 本周期该地区话题数,每条话题都会落到一个地区):选定后四段、搜索、趋势洞察、文字版文案全部按地区过滤;地区归属判定 = ①关键词中的地区词 → ②标题/摘要中的国家·城市词典(英国→欧洲、东京→日本…)→ ③语言文字特征(西里尔→俄罗斯、阿拉伯→中东、假名→日本)→ ④实时采集的英文源话题默认计入美国市场(采集主源为 HN/Reddit 等英文互联网);仅完全无信号的才落「其他」(「其他」不参与筛选)
- **话题搜索框**:输入关键词(如「宠物 / 墨西哥 / 露营」)→ 周期内话题按热度出榜(最多 50 条),可再按 🔥高 / 🌤中 / ❄低 热度筛选;搜索为**字符级模糊匹配**(查询词任一字出现在标题/摘要/关键词即命中,命中字数越多越靠前)
- **🧠 趋势洞察 + 深度分析**(四段之后,登录可见):AI 归纳趋势主线、内容选品提示、退潮提醒与下期预判(SSE 流式 + 缓存 + 模板降级,降级不扣费);趋势洞察提示词含区域热度对比
- **管理员「📝 文字版(自媒体文案)」按钮**(仅管理员可见):把当前周期报告改写为微信小程序 / 小红书爆款文案(标题候选 + 正文 + 话题标签),用于自媒体传播,不扣积分
- 游客:一句话结论 + 五张趋势图可见(钩子),明细表 / 动作卡与趋势洞察锁定,引导登录

## 设计系统(HotPilot UI PRD,2026-10-28)

全站视觉与交互对齐 HotPilot 出海选品平台 UI 规范(PRD 全文见内部归档):

- **色彩 token**:`--brand #4F46E5`(主按钮/当前导航/选中态)、`--accent #0EA5A4`(次级强调)、热度三档渐变 `#F59E0B → #F97316 → #DC2626`(热度条/折线渐变/徽标)、页面底 `#F8FAFC`、卡片 `#FFF`、中性灰阶 text-1/2/3(深色主题全套映射)
- **5 级字号**:28(页面大数字)/ 20(卡片与分区标题)/ 15(段落标题)/ 13(正文)/ 12(辅助),全站不出现 14/16/18 等中间值;强调用字重 600
- **8pt 间距**:卡片内边距 16、卡片间距 12、页面左右边距 24;圆角 8(小件)/ 12(卡片按钮)/ 999(筛选 chip)
- **交互**:卡片悬停阴影升级不上浮、焦点环 2px --brand、数字 tabular-nums 列对齐、缺失数据「—」、toast 右下角、桌面端弹层为 420px 右侧抽屉(不遮导航)
- **桌面布局**(≥1024):左侧 224px 导航(1024–1279 收起为 56px 图标栏),内容区 1216 居中;热点卡片流 ≥1440 三列 / 1280–1439 两列 / 移动端单列,<1024 保持底部 tab 栏(飞书 H5 可用)
